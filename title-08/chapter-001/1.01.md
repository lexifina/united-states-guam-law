§ 1.01. Short Title.
This Title 8 of the Guam Code Annotated shall be known as Criminal Procedure.
COMMENT: This Title is adopted by P.L. 13-186 (Sept. 2, 1976) in order to minimize possible confusion with the Code of Civil Procedure when initials are used to refer to a particular code. P.L. 15-104:7 (Mar. 5, 1980) reenacted this Code as Title 8 of the Guam Code Annotated and changed its name to conform with the new title format.
