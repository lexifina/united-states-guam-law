§ 1.48. Shall and May.
Shall is mandatory and may is permissive. SOURCE: Guam PC § 7; Cal. §§ 108, 109, 110, 111 and 112 (1971).
COMMENT: §§ 1.38 through 1.48 provide for general rules of construction of this Code and make clear (§ 1.38) that amendments and additions to statute mentioned in this Code are to be included as if they were passed at the time this Code was passed, thus clearing up any doubt whether an amendment is included, in, say, an indictment which refers to this Code and the reference in this Code to a given statute.
